# AI Founding Team Engine

**Sprint 1 – Foundations & Wireframes**

This repository hosts the AI Founding Team Engine project. The first sprint focuses on:

1. Defining low‑fidelity wireframes and user‑flow diagrams.
2. Setting up a minimal project scaffold (frontend, backend, CI/CD). 
3. Establishing authentication, basic tooling, and documentation.

All subsequent sprints will build on this foundation.
